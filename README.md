# Job Fair Sponsor Product Scraper

## Project Overview

This project was developed to support the preparation of a promotional video for the 3rd edition of Pristini Job Fair, organized by Pristini Junior Enterprise at Pristini School of AI.

The goal was to automate the collection of product images from Tunisia-HighTech's Facebook page, one of the event's sponsors, to save time and simplify the video production process.

Instead of manually downloading each image, I used Python and Gallery-DL in Google Colab to automate image extraction and organize the collected files.

## Project Objectives

- Automate the collection of sponsor product images.
- Reduce the time spent on manual image downloading.
- Organize images for promotional video production.
- Apply web scraping and automation to a real-world event marketing task.

## Technologies Used

- Python
- Google Colab
- Gallery-DL
- Facebook
- GitHub

## Workflow

1. Access the sponsor's Facebook photo page.
2. Configure Gallery-DL in Google Colab.
3. Authenticate when required.
4. Download accessible product images.
5. Organize the collected images.
6. Export the images into a ZIP archive for video editing.

## How to Run

1. Open the notebook in Google Colab.
2. Install Gallery-DL.
3. Configure the Facebook page URL.
4. Provide your own authentication cookies if required.
5. Run the notebook cells to download and organize images.

## Security and Responsible Use

- Authentication cookies must never be uploaded to GitHub.
- Download only content you are authorized to access and use.
- Respect Facebook's terms of service and the rights of content owners.
- Downloaded sponsor images are not included in this repository.

This mini-project demonstrates how Python automation and web scraping can solve a practical challenge in event marketing by making sponsor content collection faster and more efficient.
